# 🐯 Pixel Knight

A retro-style 2D platformer where you control a knight navigating platforms, collecting coins, and avoiding enemies in a pixel-art world.

## ✨ Features

- 🎮 Smooth and responsive player movement
- 🪙 Coin collection system with scoring
- 👾 Enemy obstacles and collision mechanics
- 🧱 Platform-based level design
- 🎯 Clear objective and progression
- 🕹️ Retro pixel-art visuals

---

## 🎯 Controls

| Key | Action |
|-----|--------|
| W   | Jump   |
| A   | Move Left |
| D   | Move Right |
| S   | Down / Interact |

---

## 🧠 Gameplay Objective

Traverse the level, collect coins, and avoid enemies. The goal is to survive and maximize your score while navigating increasingly challenging terrain.

---

## 🛠️ Tech Stack

- **Engine:** Godot  
- **Language:** GDScript  
- **Graphics:** Pixel art sprites & tilemaps
